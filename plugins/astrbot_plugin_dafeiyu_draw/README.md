# 小鲸鱼画图

群内支持经过群唤醒插件验证的名字、引用与同一发送者短时承接；未经验证的普通群消息仍不触发生图。同一条请求最多尝试一次生成，发送失败后的文字说明不等于图片已发送。

使用用户指定的 `https://cf.sheapi.cc/v1/images/generations`，模型 `gpt-image-2`。
固定 `stream=false`、每次一张 1024×1024 图片，不自动重试，不运行本地模型。

命令：`/画图 描述`，也支持 `/绘图`、`/draw`。
自然语言：`帮我画一只在海边摸鱼的蓝色小鲸鱼`，调用 `dafeiyu_draw`。

沿用当前 QQ 群/私信白名单，群内要求真实 @机器人。全局同时仅一个任务，默认每会话冷却 30 秒。
图片保留最多 6 张、合计最多 36MiB；密钥仅放服务器私有插件配置中。

## 自然生图与承接

是否生图由 AI 结合完整对话决定。只要 AI 调用 `dafeiyu_draw` 并提供有效画面描述，就进入生成流程，不按当前消息的关键词、正则意图或本地承接记录再次拒绝。关键词识别只提供提示和已知场景，AI 可以理解其他表达；必要主体不明确时仍应先询问。

“靠画图的形式画出来”“用图片的形式展示出来”“把手帐那一页画出来”等常见表达会提供辅助提示，画面内容由模型结合当前聊天整理。

“能照一下你们家吗”“拍一张你的房间”“帮我拍张小芽”等口语也有辅助提示；角色场景按想象插画生成，不假称真实相机拍摄。摄影知识、能力询问、转述、明确取消和调用真实摄像头的要求不强制调用，由模型判断。

每轮工具只处理一次，返回结果后从该请求的工具列表移除生图工具，不影响其他会话或下一轮。拒绝和失败均按真实结果结束；不会把本地拒绝说成接口没响应，也不承诺稍后自动重画。发送前会纠正与本轮失败结果矛盾的重试、完成或无响应说法。

同一聊天中，同一发送者的“换成蓝色”“再来一张”“背景改成夜晚”等可承接之前的画面描述。上下文最多保留 10 分钟，最多 128 个发送者与会话组合；转到无关话题、普通反馈或明确取消后结束承接。群内仍需要真实 @机器人。

明确取消、只想讨论或索要库存表情包时，提示模型不要调用生图；工具层不再以本地意图判定否决 AI 的实际调用。现有接口、冷却、白名单、并发、每轮一次生成与图片清理限制保持原样。
