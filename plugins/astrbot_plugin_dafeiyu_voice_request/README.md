# 按要求发语音

仅处理通过现有 QQ 白名单的当前用户文本。支持“用语音回复”“发条语音”“说句话”“读给我听”；“别发语音”“用文字回复”发文字。引用、代码块及唱歌请求不触发这项日常语音转换。

通过原生 `on_llm_request` 和 `on_decorating_result` 钩子复用已选 TTS 提供商与原声音色。普通聊天沿用配置中的 `trigger_probability`，只抽样一次；确定发语音后先合并本轮文字，只合成一个音频，避免原生分段造成多条短语音。嗯嗯、好的、晚安等简短回应默认用文字，明确语音要求和本人语音偏好优先。

自定义结果绕过原生随机语音，避免重复抽样、重复合成。现有 @、图片、表情包、白名单、TTS 总开关和会话开关均保留。失败保留合并后的文字，不自动重复请求。其他机器人账号不受影响。

随机自动语音最多等待 8 秒，未完成即保留合并后的文字，避免长时间拖住同会话后续消息。明确要求语音及本人保存的语音偏好默认等待 45 秒；对声明较长预算的提供商可增加到最高 90 秒。不增加合成请求次数，不修改配置的抽样概率、提供商或音色。

没有密钥配置、后台任务、独立服务、新依赖或新增端口。卸载本插件即可恢复原有全部随机行为。
