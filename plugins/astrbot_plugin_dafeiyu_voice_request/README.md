# 按要求发语音

仅处理通过现有 QQ 白名单的当前用户文本。支持“用语音回复”“发条语音”“说句话”“读给我听”；“别发语音”“用文字回复”发文字。引用、代码块及唱歌请求不触发这项日常语音转换。

通过原生 `on_llm_request` 和 `on_decorating_result` 钩子复用已选 TTS 提供商。普通消息不修改结果，继续使用原生七成文字、三成语音；明确指定的消息走自定义结果，绕过随机语音并防止重复合成。现有 @、表情包、白名单、TTS 总开关和会话开关均保留。失败回退文字，不自动重复请求。

没有密钥配置、后台任务、独立服务、新依赖或新增端口。卸载本插件即可恢复原有全部随机行为。
