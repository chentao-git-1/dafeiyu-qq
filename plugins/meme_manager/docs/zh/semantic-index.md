# 自动收集与向量更新

在设置中心选择 **Tool 语义检索** 或 **辅助模型语义检索**，然后打开 **自动收集 → 审核与入包**。新增的“自动收集后生成向量”默认开启，仅在启用语义检索时显示和生效。修改后点击“保存并应用”。AstrBot 原生插件配置页中，同一开关位于“语义检索与图包语义化”，也随语义检索开关显示或隐藏。

![自动收集向量设置（模拟数据）](images/automatic-vectors.png)

开启后，图片自动入包或经人工审核接收后，后台会合并短时间内连续入包的图片，复用兼容的已有向量，仅为新增或语义变化的图片生成向量。调用配置的向量模型会产生相应费用。仅进入待审核列表、尚未接收的图片不会生成向量。

描述已完成的图片可直接参与增量处理。修改接收分类导致描述失效、待分类或描述不完整的图片，需要先到“语义化”页面完成描述。它们不会阻断同包已有有效向量的检索；语义已变化或磁盘文件已删除、替换的旧向量不会作为候选返回，检索会补取其他有效图片。

![管理页的增量处理与重建按钮（模拟数据）](images/incremental-vectors.png)

| 原入口 | 当前入口与用途 |
| --- | --- |
| 表情包管理 → 按当前维度重建 | 原入口保留，全量重新生成向量；更换模型或维度后使用 |
| 日常新增图片后通过重建补齐向量 | 表情包管理 → 增量处理；复用已有向量，只补新增或变化内容 |
| 语义化 → 高级维护 → 建立或重建索引 | 原入口保留，兼容索引按增量处理 |

关闭自动生成后仍可手动点击“增量处理”。首次建立索引时会为所有已完成描述的图片生成向量；已有索引的模型或维度发生变化时，增量处理会提示改用全量重建。向量任务失败时，图片及已保存描述保留，可修复模型配置后手动重试。图包忙碌时保留自动更新任务，资源释放后补跑；暂停或中断的语义队列需先继续完成或清空，增量处理不会覆盖原队列。关闭人工审核时，仅本次收集且因忙碌暂留的新图片会自动重试入包，原有人工待审图片不受影响。旧索引损坏、清单缺失或未变更向量无法读取时，增量处理会要求全量重建，不会静默重新请求整个图库。管理页会定期刷新当前包的向量状态。
