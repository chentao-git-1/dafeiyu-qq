# 小鲸鱼唱歌

基于小米 MiMo 官方 `mimo-v2.5-tts` 歌唱模式的轻量 AstrBot 适配器。云端生成歌声，服务器通过现有 OneBot 接口发送 WAV，没有本地模型或额外服务。

用法：

- `/唱歌 蓝色尾巴划过海面，星光落在我的指尖。`
- `/sing <歌词>`
- 对机器人说“给小鲸鱼写四句原创歌词并唱出来”，由 DeepSeek 写短歌词并调用 `dafeiyu_sing` 工具。

默认唱歌音色为中文女声“茉莉”，使用通过试听的清唱指导，强调四四拍、音符起伏和句尾延长音。唱歌使用预置音色，日常说话仍走原先的晓晓 TTS。当前不做原曲搜索，也不保证复现指定歌曲的原版旋律；MiMo 的音色克隆型号不支持歌唱模式。

默认限制为每段 2～160 字歌词、全局一个生成任务、每个会话 90 秒冷却、75 秒请求超时，音频缓存最多 6 份且不超过 30MiB。群和私信均有独立白名单，配置中的密钥属于敏感字段。空密钥和 `enabled=false` 时不会发出云端请求。

由管理员通过 SSH 隐藏输入 MiMo 密钥后启用。配置及缓存保存在 AstrBot 持久化数据目录；生成失败仅返回经过筛选的状态，不把远程响应或认证头发给群友。

官方接口说明：https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/multimodal-understanding/speech-synthesis-v2.5
