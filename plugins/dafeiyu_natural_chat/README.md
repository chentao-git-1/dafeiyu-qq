# 自然相处与事实校验

沿用已配置的 QQ 账号、白名单、管理员权限及回复配额。输入在图片识别和引用展开之前留存，只采纳当前发言者自己的直接更正。

明确的本人下车站、列车终点与游戏平台分开保存，按联系人及会话隔离；行程事实 12 小时过期、游戏平台上下文 24 小时过期，下车完成或明确要求忘记时清除。疑问、第三人转述、引文、假设与不完整车次不写入事实。

实时查询需要本轮成功搜索回执；提醒承诺需要原生 `future_task` 的成功回执，并再次检查调度库中任务启用、归属发言者及会话。没有回执就如实说明，保留现有实际调度能力。对明显先到后发的时间矛盾、未安排的未来提醒、无限记忆承诺和未说明的实物故事增加发送前校验；这些针对常见表达的规则不代替所有事实核实。

收到单张原图后五分钟内，可以直接说“这个表情包拿去用”，真实保存成功才确认；接着说“发给我看看”会回发原始文件，不重新画图。图片按联系人及会话隔离，保留原始字节并校验摘要，不自动进入公共表情库或空间素材。支持“清空我的图片收藏”。单图最多 6 MiB、2400 万像素，总量最多 64 MiB、200 张；多图歧义、损坏、失效或处理失败均不声称成功。

短回应不追加问卷式追问或生活指挥；省略号不作为确定情绪的证据。图片不用于推断发送者身份、当前地点、拍摄时间或游戏平台。保留原有技术问答、隐私拒绝及明确要求的故事表达。

普通闲聊通常一两句，亲近、玩笑和自己的看法按当前话题出现；表达反馈与身份提问分开处理。本人直接嫌语气机械或像客服时，当前回复按反馈调整，并沿用既有个人偏好机制保存“简短优先”；引用、转述、图片和身份询问不据此改设置。短赞美包含常见表情时也自然收尾；技术解释、明确请求和工具结果保持原义。

0.7.2 将随口分享近况、轻松玩笑、语气反馈与实际请求分开提供表达方向；明确求分析、提醒和技术问题优先，不按普通分享收住。稳定偏好改用简短描述注入，重复的客服式邀请纳入现有去重。普通进展中的 `unknown` 发送回执转成“还不能确定”的说法；询问回执、代码、引用或原文时保留原始细节。不增加每轮模型调用或主动发送。

分享、玩笑和纯语气反馈已有陈述反应时，可去掉后续无必要的问句；只剩问句时保留原文，不生成统一兜底台词。引文中的问号、实际请求、代码和工具轮次保持完整。它是表达收尾保护，不替代模型对语境和事实的判断。

0.7.3 对近况中“钥匙找不到”“电脑打不开”等实际困难优先保留帮助与必要追问，接梗反问保留；普通吃饭、回家等分享减少未经请求的生活指导。称呼目录按话题加载，本人称呼及事实核对不变。没有对应任务时处理常见作品和后续通知承诺，保留想法、引文、故事及已核对的本人任务；不自动创建承诺对应的任务。共同的已发送私聊衔接及限制见 `docs/CONTINUITY.md`。
