# DeepSeek 余额查询

0.3.1 使用两档提醒：每 10 分钟查询 DeepSeek 人民币总可用余额，严格低于 1.00 元提醒主人，严格低于 0.70 元进入亲友求助。正好一元不启动，正好七毛只提醒主人；恢复七毛停止未发求助，恢复一元才结束整轮。

先私信爸爸（7000000001），两小时后仍不足时白天再提醒一次；低于七毛无需等待六小时。亲友仅在北京时间 09:00（含）至 21:00（不含）通知，每天最多开启一轮。每轮最多锁定两位，每人一次，拒绝、静音或不可联系后跳过，不补第三人。初次主人提醒保留即时规则。

候选按最近七天确认送达的真实人类对话轮数排序，私群合并、重复事件去重；排除主人、自身和已标记机器人，再检查实际好友关系、私聊权限和主动通知许可。不要求有固定称呼，不从累计 `turns` 或记忆库推算历史。亲友文案不含余额、排名、账户信息，也不要求代付。提醒使用本地文字，独立于聊天模型、语音和回复限流。

爸爸私信“我去充”“正在充”或 `/饭钱暂停` 暂停催促两小时；“充好了”或 `/饭钱检查` 立即核查真实余额。`/饭钱状态` 查看最近状态，`/饭钱继续` 提前恢复。自然语句仅在低余额轮次中生效，引用、疑问、其他联系人、群聊和定时任务不能暂停监控。

通知状态保存在挂载的 `plugin_data/astrbot_plugin_dafeiyu_balance/state.json`，目录 0700、文件 0600。发送前落盘；回执不明或重启遇到发送中状态时不自动重发同一条。QQ 离线时保留待提醒状态，明确失败的发送每十分钟可再试，查询失败不当作低余额或恢复。

确认发送后同时保存实际通知原文。本人后续私聊可将近 24 小时、同联系人且有发送回执的通知按时间补进模型上下文；已有记录去重，旧聊天保留。对“好的鲸鲸”等直接应声，结合最新实际发出的消息衔接，不跳回几天前的话题。应声不表示已转告、已读或充值成功，不重复通知。

旧通知仅在目标会话的 QQ 原始记录中核对到相同消息编号、发言账号及时间后补原文。未知、失败、过期、其他联系人、群聊和定时事件不作为这条私聊的已发送上下文；无法确定插入顺序时只提供带来源的本轮资料，不猜测重排。`text` 为状态文件的可选新增字段，旧版可忽略，回滚不得用旧账本覆盖新的通知状态。

私信 `/余额`、`余额`、`查余额` 或 `你还剩多少钱`；白名单群需要先实际 @ 机器人，群内所有成员均可查。私信仅允许管理员 QQ 7000000001。

查询的是 DeepSeek 整个账户的总余额、充值余额和赠金，不是本机器人单独的用量额度。直接调用官方 `GET https://api.deepseek.com/user/balance`，不需要聊天模型，因此余额不足时仍可尝试查询。

仅使用当前配置中官方 DeepSeek 来源的密钥，不另存或输出密钥及原始错误响应。统计由现有社交插件的独立元数据表提供，不新增服务或端口。旧余额状态迁移与回滚条件见 `docs/MIGRATION.md`。

官方文档：https://api-docs.deepseek.com/zh-cn/api/get-user-balance/
