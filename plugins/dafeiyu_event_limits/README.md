# DeepSeek 峰谷回复限流

- 北京时间周一至周五 09:00–12:00、14:00–18:00 为峰时；其余时段、周末及中国节假日全天为谷时。
- 管理员以 AstrBot 当前 `admins_id` 配置为准，私聊和群聊均不受个人或群回复额度限制，也不占用普通用户的群额度。配置中的管理员变更会直接生效，不通过昵称、自称或 QQ 群管理员头衔认定。
- 普通用户在峰时采用滚动 1800 秒窗口：同一 QQ 用户跨私聊及各群累计最多 10 次回复，每个群累计最多 15 次回复。
- 谷时不限制回复次数，也不消耗峰时额度。群聊原有回复密度限制关闭，日常聊天的触发与人格逻辑仍由原插件处理。
- 计数单位为一次回复。相同 OneBot 消息触发的多段文字、语音、图片计一次；没有回复的入站消息不计。发送失败释放尚未确认的额度。
- 主动群聊消息计入群额度；主动私聊消息计入普通收件人的个人额度，对管理员私聊不计额度。额度满时跳过，不积压消息；恢复时间提示按下文去重发送。
- SQLite 计数位于 `data/plugin_data/dafeiyu_event_limits/replies.db`，重载或重启保留。只保存标识与时间戳，不保存聊天正文。升级后清理窗口内的旧管理员额度记录，保留普通用户记录。
- 管理接口 `/dafeiyu_event_limits/status` 沿用插件鉴权入口，返回当前时段、规则及汇总，不返回个人计数或聊天正文。

## 维护

定价依据：[DeepSeek 官方模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

`quota.py` 中已加入 2026 年国务院公布的完整放假日期。以后每年公布放假安排后更新 `HOLIDAY_PERIODS` 并热重载本插件。尚未收录年份仍识别周末和固定法定节日，并在状态接口返回 `holiday_calendar_current=false`；不猜测春节、清明、端午、中秋及调休日期。

群聊插件 `utils/proactive_chat_manager.py` 在主动对话前读取共享额度，且尊重 LLM 请求钩子的停止标志。停用本插件时共享检查自动失效。
# 回复额度提示

峰时额度耗尽时，同一用户或已满额的群在本次等待窗口内最多收到一次恢复时间提示。提示使用本地固定文字，不调用模型，不占用 AI 回复额度；后续正常回复仍受原有每人 10 次、每群 15 次限制。重启会清空提示去重缓存，回复额度账本继续持久化保存。
