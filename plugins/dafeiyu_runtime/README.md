# 回复链路保障（0.3.2）

保留发送者级连发合并和消息去重，已经生成的回答不因后续消息到达而被直接丢弃。普通回复、工具请求和媒体发送沿用同一条消息的额度记录。

- 模型实际开始处理后 25 秒尚无进展时提示；同一会话 60 秒内最多一条，群内提示会 @ 对应发送者。排队期间不发进度提示，提示与正式回复顺序发送。
- 整轮上限 180 秒，单次 QQ 发送上限 40 秒。
- 超时后停止该轮并说明结果，已经可能执行的发布、生图等操作不自动重试，过期任务不得再发送迟到回复。
- 语音或图片发送失败时尝试一次文字补偿；语音优先沿用原文。补偿不视为媒体发送成功。
- 未启用语音识别且模型不支持音频时，纯语音消息直接说明需要文字，避免假装听懂。
- 纯 QQ 表情转为聊天可读的表情描述；空消息及不支持的消息组件按正常跳过处理，避免误发故障提示。
- 会话关闭 AI 等正常跳过不作为空回复故障；工具已确认发到当前会话的文字或媒体计为送达。
- 空白输出不计为送达；分段回复中途发送失败时说明部分未确认，不自动重发已发出的内容。
- 主循环停止推进超过 8 秒时，由独立线程采样调用位置，最多每 30 秒记录一次；不记录局部变量、消息正文或密钥。
- 状态接口增加完成、超时、过滤、发送失败、文字补偿和卡顿采样计数，以及守护是否生效。

群聊上下文继续共享；排队与处理均计入整轮时限。QQ 断线时本地不能保证提示送达，状态会记录发送失败。阻塞采样用于定位具体耗时调用，不宣称历史卡顿根因已消除。

新增私有的已确认主动消息记录，覆盖本账号的直接私信与跨会话发送，按联系人及原对话衔接，保留 90 天或最多 5000 条。只观察 API 发送结果，不发额外 QQ 或重试；状态不包含号码和正文。原生普通模型回复沿用既有历史。新增会话锁等待、首个完整模型响应和上下文长度等数值诊断，阶段有重叠，首个响应不等于流式首字。详细范围、遗忘和回滚见 `docs/CONTINUITY.md`。
