# 鲸鲸 QQ 路由与私聊核对

保留原有好友、群目录及文字/语音代发功能。新增 `dafeiyu_private_history` 只读工具，并为管理员私聊中的回复状态增加实时核对。

- 仅 QQ `7000000001` 本人在机器人 QQ `7000000002` 的真实私聊消息中可读取；群聊、其他用户、定时任务和其他平台不能调用。
- 联系人必须是当前真实好友且在私聊白名单中。支持 QQ、昵称和已确认称呼；同名或多人指代不明确时不猜测。
- 询问“某人回了没有、后来怎么说”等问题时，直接向 NapCat 查询机器人账号自身与目标好友的最近 60 条私聊；模型最多接收其中最近 12 条及最新收发记录，均含北京时间与方向。
- “她回了吗”等追问可沿用最近明确的联系人。旧摘要、工具返回内容不会自行成为指代依据。
- 共享记忆、旧会话摘要、空查询结果和查询失败都不能证明“对方没回”。已有回复时不再笼统断言一直没回；询问某一条后续消息需要明确对应时间。
- 在最终文字/语音生成前及发送给管理员的工具消息上，纠正无依据的回复状态与“没刷新、消息卡住”等技术原因。
- 查询不会发送 QQ 消息，不改写聊天记录或长期记忆；状态接口仅增加读取、失败与纠正计数，不返回聊天正文。

本功能核对的是账号可获取的最近聊天记录，不是手机屏幕、QQ 已读回执或无限期完整历史。超出查询范围或接口不可用时必须说明尚不能确认。

核对结果先用口语回答当前问题。程序纠正无依据的回复状态时，默认只引用最多 100 字的真实内容；对方问时间、原话或核对记录时，再提供时间和最多 240 字的引用。截断时明确提示后面还有内容，不擅自改写金额和含义；旧回复只说明“有回过”，不声称刚刚新回。查询来源、范围、权限和事实核对规则保持不变。
