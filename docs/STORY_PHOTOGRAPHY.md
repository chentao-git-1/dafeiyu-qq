# 鲸鲸的角色生活照片

用户希望鲸鲸把自己的画面视作她拍下的照片。角色生活已经设定在临湾，因此自己的自拍、住处和城市生活画面可以用摄影者口吻自然分享，不再要求每次解释为“想象插画”。照片构思、取景和措辞由模型选择，没有固定等待或分享台词。

原生图片工具增加可选 `presentation`：新图默认 `story_photo`，明确画作、图表或设计稿用 `artwork`。连续修改在未指定新类型时继承同人同会话的上一张；指定新类型可以切换。`/画图` 命令仍明确作为绘图处理。真实相机、技术来源或现实取证问题继续按实际来源说明，照片不会变成真实联系人的经历。

聊天和自主活动的照片记录同时保存两种信息：角色含义为“鲸鲸拍下的照片”，生产事实为 `generated_image`，`physical_camera_used=false`。只有真实生成并确认发送后才进入受托作品记录；失败或发送不明不会写成已送达照片。旧记录读取时默认为 artwork，新增列在正常写入时兼容迁移，不批量重写旧图。

夜间自主计划的 drawing 活动也支持 `presentation`，默认可以构思角色照片。成果进入自身回忆、成长与当天素材时保留照片含义及生成来源；图片调用次数、执行窗口和余额检查沿用原机制。空间原创配图使用同一角色照片视角，用户明确提供的图片继续使用原图；正文仍由模型自主表达。

验证全部使用模拟文字／图像提供商、捕获的发送、临时库和线上旧作品账本副本。覆盖照片送达、发送不明、重启读取、类型继承与显式切换、跨联系人隔离、遗忘和旧模式兼容。不会为了验收额外生成一张收费图片或试发动态。
