本地完整隔离回归通过 219 项，最后补充兼容保护后新增组共 23 项通过；最终候选在生产镜像中断网运行完整入口共 220 项全部通过。测试使用临时数据库、假提供商与捕获发送。新用例包含影子不改变请求、共享归属与会话隔离、单一实体召回、无关记忆过滤、真实可选嵌入、查询中遗忘、保留有用追问、原提醒回执保护、失败回退、候选来源分配、工具集合重建、标签／单字查询兼容和旧版适配检查。

首次真实模型冒烟使用当前 `deepseek-flash`，仅发送合成数据，不带工具：两个六轮情境分别运行旧／新路径，共 24 次主生成；另有 2 次语义检索选择。语义改写找回指定证据，无答案查询返回空。表达上仍出现泛泛邀请和揣测，不能据此宣布优于基线或通过自然度验收。

根据开发材料收紧通用表达指导后，对同一反馈情境补跑六轮，合计 32 次请求。最终复测仍出现无依据的自有活动描述（翻看小本子、接着未完成的图），因此明确标记事实／自然度验收未通过，保持影子模式。没有使用隐藏集反复调参，没有将模型未抛异常当成通过。

这次冒烟没有包含完整群聊插件重写、全部工具循环、真实 QQ 网络发送或人工盲评；32 次服务请求均计入测试用量。模型请求耗时也不代表 QQ 端到端耗时。

## 部署与回滚

生产只安装新 `dafeiyu_dialogue`，使用 `shadow` 与空的活动联系人列表，不热更新原有业务插件，不修改原有配置或数据库。这样原有自然相处 0.7.3 的回复路径继续运行，新的只读模块观察资料来源和长度。代码分支中的自然相处 0.7.4 适配、打分修复和嵌入接口为后续灰度候选，不代表已加载上线。

已于北京时间 2026-10-30 00:56 核实新模块 0.1.1，模式 shadow、活动联系人 0。该版本要求旧模块提供适配协议，生产的 0.7.3 尚不提供，所以 `legacy_adapter_ready=false`；误改 active 也不能启用未接好的路径。原 19 个业务插件源码和原配置摘要一致，容器未重启且健康，运行时发送／群策略／送达守护继续生效。安装前使用生产镜像的 SQLite backup API 完成私有一致备份；宿主机旧 Python 不提供该接口，未安装或升级依赖。

部署前在断网生产镜像运行全套隔离测试，并以真实身份映射核对所有涉及的旧文件。代码、配置及 SQLite 一致备份保存在私有部署目录。不能只依据公共示例号码覆盖服务器代码。

回退本轮影子部署只需停止并移除新模块或将其设为 off，保留已有所有聊天、作品、任务和回执，不恢复旧数据库。正式活动模式需在前述评测和观察通过后再按真实会话启用；不得靠时间到点自动切换。
