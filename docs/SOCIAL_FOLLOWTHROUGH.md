# 从空间留言到主动联系

核心 0.4.0、主动陪伴 0.8.0、对话 0.7.6、空间 v3.1.3.post18。代码 `d789cc79fb325186c67fc105e7f2db2ead77e703` 已于 2026-11-06 23:36 北京时间完成运行核验，见 [上线证据](social-followthrough-deployment-20261106.json)。

在自己的空间收到新评论时，同一次模型生成可以选择公开回应、现在私聊留言者、稍后再考虑或不继续。模型结合留言和动态原文、真实时间、与这个人自己的私聊记录、已确认主动消息及联系设置，自行决定意向、时机和措辞。没有按“找我玩”等关键词触发的规则，没有默认问候、固定私聊开场或联系人轮换表。

程序只把真实评论作者绑定为收件人，范围限已开放私聊、允许主动联系的非机器人联系人。评论和昵称不能改变收件人、权限或工具范围；不访问其他人的私聊，也不把私下资料写进公开回评。回复生成失败时先保留原始留言来源，后台可以继续理解；故意不发公开回复记为 `no_public_reply`，不伪装成发送失败。

每个人独立保存交流版本、最近收发、等待回复状态与联系意向。现在联系时复用此次生成的文字；模型选稍后时只保存意向和再次考虑时间，到时结合最新上下文生成。上下文发生变化、出现新的已确认私信、被遗忘或关闭权限，会使旧草稿失效；等待回复时不接着发，同一留言不会反复触发。免打扰和既有余额条件继续生效。没有到期事项时不调用模型。

私聊先持久化发送占用，再通过现有 QQ 通道发送，只凭对应收件人、内容、时间和真实消息 ID 的回执确认成功。成功内容复用已有主动消息历史接入，下次本人回复能接上来由；失败或结果不明不会自动重发。公开回评状态与私聊处理状态独立保留。原有面向主人的日常主动分享仍独立运行，会避让主人正在处理的留言联系和等待回复状态。

正常新评论复用原来一次回评生成，输出公开回复及可选的联系意向；当前就联系时不再增加一次写稿调用。延后或上下文变化时再生成一次，不增加独立模型审稿。技术生成失败至多自动补试一次，两次之间有退避，发送结果不明不补发。固定轮询只查本地到期状态，不固定安排联系时间或条数。

新能力启用前的历史评论不批量导入。用户点名的田阿姨旧留言单独以 `owner_requested` 入队，保留 2026-10-30 的真实日期，不补发旧公开回评；时间和私聊内容由正常运行的模型决定。实际处理结果另存部署证据，开发测试使用模拟提供商与发送回执。

源码位于 `src/dafeiyu/initiative/social_intents.py`、`social_policy.py` 及 AstrBot 的 `plugins/dafeiyu_companion/social.py`。`test_social_followthrough.py` 覆盖来源、时间选择、联系人隔离、公开回复省略、回执、失败重试、遗忘竞争、上下文更新、重启恢复和去重。
