## 自动回归

完整入口 `python scripts/run_tests.py` 在本地 Python 3.12 和服务器现有生产镜像中均通过 **286 项**。其中原有回归 240 项，新认知路径 46 项。最终 Git 索引会另外导出独立快照执行同一入口，避免只测试工作区而发布另一份代码。

生产镜像验证使用独立容器、断网、只读候选源码和依赖，不挂载运行配置、聊天或记忆数据库。没有真实 QQ 发送、空间发布或付费媒体生成。重点覆盖真实身份、来源/版本、确认后写入、隐私竞态、保留其他人来源、原生历史一致、请求授权和并发 JSON 传输、主动发送中途来信取消、未知结果不重试、格式修复不重复执行动作以及语音最终文本绑定。

这些是确定性回归。测试中的假提供商不能证明真实模型会稳定识别假设、完成状态或虚构经历。

## 已确认的失败与未验收项

- 最终候选 353 轮生成正常进入合同路径，**31/384 轮退回保守失败提示**。结构化输出、来源标注和核对仍会失败；“拦截草稿”不能作为自然度通过。
- 另一组 20 轮学习探针中，真实条件偏好、取消陶艺课、收音机完成、选择性遗忘、本轮不保存、引用/第三人反例等得到实际数据库证据；仍有一例把“假如以后搬家再学竹编”写成持久条目（`learning:8`）。因此“假设不得写入”未通过，持续偏好/事件语义准确率也不能用单元测试代替。
- 一些学习探针仍出现多余追问、泛泛邀请和过于保守的失败提示。自我经历是否应声明来源依赖模型标注，漏标仍可能绕过按需核对，尚无独立证据证明无编造。
- 已生成 **64 组 A/B 顺序均衡随机的完整对话盲评材料**，支持本地保存与导出评分；没有真人评分，不报告胜率、平局率或置信区间。
- 原生真实工具循环、完整群聊插件组合、真实语音自然度及综合费用未验收。群聊新路径仍未启用。
- 原方案要求的小流量观察同时满足至少 3 天和 100 个有效回合；本轮候选尚未开始这项试运行。

## 后续修改、推广与回滚顺序

1. 先针对失败机理修正结构化输出/元数据恢复、假设与持续性的判定、按需核对漏标和过度拒答；维持来源、主体、条件与版本边界。使用另行准备的未曝光表达与完整连续情境复验，不给上述失败句增加特例文案。
2. 用人工标注的真实规模资料验证完整召回链：精确率 ≥90%、改写 Recall@5 ≥85%，无答案与跨用户反例单列。持续偏好隐藏改写 ≥90%，引用、第三人及假设不得误写。
3. 完成独立真人盲评，目标为相对基线胜率至少 60%，同时报告样本量、平局与置信区间；连续情境关键人/事/时间无错接率目标 ≥90%。现有 64 组材料可用于诊断，需要新的独立验收资料。
4. 实测同模型、同服务器、无工具媒体条件下的端到端排队、生成和送达；再把学习、召回、反思、重试、工具失败、主动联系和媒体计入每个有效回复的综合成本，初始目标 ≤基线 1.25 倍。
5. 正式变更前重新读取 active 联系人、实际版本与业务文件差异，保存私有源码/配置及 SQLite 一致备份，不清空旧库。配套发布候选版本，先影子核对，再仅主人私聊小流量；主动策略和语音分别受开关控制。
6. 同时满足至少 3 天和 100 个确认有效回合，并完成 active 路径关闭/恢复演练后，再加入明确选择的联系人，群聊最后单独验证。单独关闭观察器不等同于完整 active 策略回滚。
7. 回滚使用功能开关与兼容源码恢复；禁止用旧数据库覆盖期间新增数据。学习源库、当前/历史版本及派生索引按归属撤回，备份保留与删除另行管理。确认新路径稳定后再移除已退出的旧注入和补丁，S7 才能验收关闭。
