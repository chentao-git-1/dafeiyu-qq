# 随机主动联系

**2026-10-31 已上线，14:29（北京时间）核验通过。** 用户要求主动联系不要固定每天最多两条。部署代码 `9c4ab8df4ed192c57c1202e957f1b55f4c7b0263`，主动陪伴模块升级为 0.4.2。见 [部署与调度证据](random-initiative-verification.json)。

## 运行方式

- 每个北京时间自然日随机生成 0～4 次主动联系机会，在 09:00～21:00 的可用时间内分散安排；不再固定上午、晚上各一个机会。当天启用时只规划尚未经过的时间，不补发错过的机会。
- 机会不要求用完。模型结合实际新作品、待跟进事项、最近互动和已经分享的内容，决定是否值得发送。实际发送量可以小于随机机会数，也可以为零。
- 每次主动联系后随机等待 90～240 分钟才允许再次主动联系。原有“近期仍在聊天就收住”和“未收到回复就不追发”继续生效。频率与时机随机，正文仍由模型生成，通常一两句。
- 当天次数、机会时间及联系间隔写入现有 SQLite。重启不会重新抽签、刷新名额或清除等待回复状态。旧的收发记录和已使用来源继续参与去重；一份资料不因当天有多次机会就重复发送。
- 每次机会最多一次模型评估，决定不发、失败或机会过期后不在每分钟循环中重试。发送前再次核对机会、身份、来源、交互版本及等待状态，生成期间收到消息会阻止旧决定继续发送。发送结果未知时不自动重发。
- 主动联系范围继续限主人，保留原通知许可、余额、真实来源和短回复边界。用户明确安排的提醒按约定时间执行；这次随机化作用于自主联系。
