# 自主探索与生活内容

2026-11-06 **18:14（北京时间）已部署并核验**。核心 0.3.1、日常 0.7.1、统一对话 0.7.1，代码 `a9f8e89efe41eae0e4ff3665834a65b096ee0174` 已推送 main。见 [部署证据](life-variety-deployment-20261106.json)。

当前用户希望生活更丰富，仍由模型选择兴趣、数量和安排，不使用固定话题表或强制轮换。新增能力保持北京时间 23:00 规划、次日 09:00–21:00 执行。

此前规划只带每个项目的最近一条作品，旧项目实际重复了多少次不可见；日常只有阅读、写作和绘画，阅读直接打开搜索的第一个有效结果。允许新兴趣的提示并没有提供先浏览、再选择的活动过程。

这次补上三个环节：

- `exploring` 使用模型自选的问题做一次公开检索，在通常那次活动生成中选择感兴趣的一条标题／摘要，也可以不选。不增加独立选题或评审模型。只保存选中来源和自己的感受，清楚标记为摘要，不能等同于读完或核实全文。
- 夜间计划可用 `after` 指向当天较早的活动。到点才绑定已完成、作品散列有效的材料；阅读承接探索时直接提取选中网页，省掉重复检索。来源未产生或作品已撤回就跳过依赖项，独立项继续。未来计划不能提前成为经历。
- 规划看得到近期已完成活动按项目、天数、形式及不同来源数的分布，仍只附每个项目最新正文。`life_direction` 保存主人当前希望的方向，默认留空；部署时写入本次“生活更丰富、兴趣主题与次数自行决定”的要求。统计不触发强制换题，初始爱好不充当允许题材表。

作品、来源和反思继续进入自身回忆与已有成长过程；聊天可见正在真实执行的探索，但没有运行证据时不能宣称正在忙。探索失败不会循环重试。正常运行中，模型选做探索才发生一次检索与一次通常的活动生成，结构修复仍沿用现有最多一次机制；本次开发不用真实模型、检索或生图测试。
