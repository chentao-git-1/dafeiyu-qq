# 部署说明

本仓库是去除私人标识的源码快照。先在独立环境配置账号与权限，再启用主动消息和空间发布。

## 身份映射

复制根目录 `identities.example.json` 到仓库外的私人位置，保留左侧示例号码，仅修改右侧的号码。

| 示例号码 | 用途 |
|---|---|
| 7000000001 | 主人 QQ |
| 7000000002 | 机器人 QQ |
| 7000000011、7000000012、7000000013、7000000014 | 有固定称呼或别名的亲友 |
| 7000000015、7000000016 | 历史测试联系人示例 |
| 7000000101、7000000102 | 开放群示例 |
| 7000000201、7000000202 | 其他机器人示例 |

脚本将身份映射应用到复制后的插件，不修改 Git 仓库里的源码，不写入凭据，也不覆盖已有插件目录。升级已有服务时应先备份并单独审查变更。

人格文本中的示例号码需按同一映射替换后，再导入 AstrBot 的人格管理界面。固定称呼可以按自己的关系修改；陌生人的昵称或正文自称不能赋予管理权限。

## 框架和插件

框架源码位于 `framework/`，版本为 4.29.1。按其 README 安装依赖并构建前端；编译后的管理面板没有重复提交。

安装外部插件：

```sh
python scripts/install_plugins.py --target /path/to/AstrBot/data/plugins --identities /private/path/identities.json
```

在本地管理界面配置 OneBot / NapCat、DeepSeek 以及实际使用的语音、画图、唱歌和空间账号。运行配置和会话数据由 AstrBot 在本地生成，本仓库没有这些数据。

## 基线行为

- 群聊仅实际 @ 机器人触发，回复引用原消息。
- 好友空间仍每天北京时间 9、15、21 点检查，自己的评论每 600 秒检查。
- 自动空间动态改为北京时间 21:30–22:30 的每日一篇晚间日记。
- 余额低于 1.00 元提醒主人，低于 0.70 元进入两位合规好友求助阶段，不再等待六小时。
- 开发代码包含确认送达统计、独立公开摘要拒绝和旧状态迁移。部署前按 `MIGRATION.md` 备份并核对实际加载版本，不能仅凭文档认定生产已升级。
