# 真实相处中的关系记忆

关系记忆保存鲸鲸对当前人的具体看法、信任和亲近感，使用文字与情境描述，不使用好感分数、等级、聊天次数或自动衰减公式。身份称呼和操作权限独立保留：觉得信任不授予工具权限，发生分歧也不会改写固定身份。

## 形成与变化

在正常聊天的同一次 JSON 生成中，模型可选择提出一项 `relationship`，或省略。提案包括 `aspect`（impression／trust／closeness）、主观看法 `view`、适用情境或保留意见 `context`、当前本人原话中的 `evidence`，以及修订编号和版本。不要求每轮评价对方，不把第三人、引用、假设或自己编的经历当作当前人的直接互动。

模型依据真实上下文和已保存的看法自主选择保留、修订或撤回。每条结论是有条件、可改变的主观看法，不是对方的客观人格。相同文字和情境不重复积累；没有记录不等于陌生。当前上下文保留有限的简洁看法，原话和历史版本仅在明确查询变化原因时读取，避免反复翻旧事。每会话最多保留 12 条活跃看法是材料容量限制，不会改变亲近程度；在已有情境内继续形成理解时修订原条目，暂不采用的看法可撤回。

结构和原话归属在本地校验，不额外调用模型审稿。记录只在正常回复完整确认送达后提交；送达不明、部分送达、解析失败、拒绝保存或遗忘后的迟到请求均不提交。它记录当次本人原话、真实送达回复与版本时间。新请求按已提供版本更新，不能覆盖另一会话或较新的修改。

## 范围、遗忘与行为

记录位于原 `learning.db` 的独立关系表，与学习源共用同一个撤回版本屏障。按真实 QQ 和会话范围读取：私聊不进入群聊、其他人或公开空间；群内只读取当前发言者在同一群的记录。它不进入共享事实检索，不作为执行权限或客观事实证据。

`dafeiyu_personality(status/history)` 可只读查看当前看法及变化依据，`dafeiyu_cognition(review/forget)` 可查看并按已提供编号删除。全部遗忘会同时清除相应关系及历史原话；删除同一学习源的资料也清理关系版本中依赖的原话。旧记忆库无法提供精确派生关系的删除请求，会保守清理该范围的关系记忆。隐私变更与删除在同一数据库事务中完成，旧请求不能重新写回。

原主动私聊和留言承接流程读取对应联系人的关系记忆，帮助决定何时联系和怎样表达，仍使用已有正常生成。初次留言回评与私聊复用同一次生成；关系记忆属于私有材料，不写进公开回评，不增加消息次数或权限。

语音适配器停止读取、累积和使用旧 `relations.json` 的聊天次数；该文件作为旧数据保留，不自动转换成感情。去掉 6 次／15 次、3 天等熟悉度分档，以及按固定关系强制亲近的语音分支。正常回复可用可选 `delivery` 描述当轮语气，由同一次模型生成决定；与最终文字哈希一致才用于 TTS，不一致回到普通表达。旧身份标签仅用于准确称呼。

## 费用与上线

`relationship_memory_v1` 默认关闭，已有服务在本次部署中按用户授权开启。关系机制不增加模型调用次数、后台审稿或历史批量评估；会增加少量关系上下文和偶尔出现的提案 token，优先完整聊天回复，预算不足可省略提案。普通聊天输出上限保持不变。

不导入旧聊天次数，不编造上线时的好感或信任，不为了验证而向真人发送测试消息。上线后从真实相处中逐步积累。回归采用模拟模型、捕获传输、临时数据库，并在生产镜像断网执行；另在真实数据库副本上验证新增表与隐私处理不改变原有记录。
