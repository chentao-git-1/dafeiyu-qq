# 对话衔接与交付依据

当前组合：运行模块 0.3.2、自然相处 0.7.3、消息路由 0.1.9、余额 0.3.2、语音发送 0.2.2。

跨私聊询问新回复时，以已知发送消息与来信的时间为界。最新来信早于最新发送时，不再拿旧来信兜底新回复；只说明当前查询范围内还没查到后续消息。时间相同到秒时不猜顺序。实际新来信只证明有新消息，不自动证明是在回答指定问题、已读或完成事情。明确问从前的话保留历史语境。

运行模块观察本账号 `send_private_msg` 和私聊 `send_msg` 的成功返回，不改变原始请求或结果，也不重试。只接受真实非零消息编号；失败、超时、布尔值、未知返回不写入已确认记录。普通当前主模型回复沿用原生历史，独立直接发送与跨私聊发送进入私有 `plugin_data/dafeiyu_runtime/outgoing.db`。记录包括实际正文或媒体类型标签、目标、确认时间及原对话编号，保留 90 天或最多 5000 条。媒体标签不冒充图片识别结果或语音转写。

后续真实私聊按同联系人和对话编号读取，按可信时间补入 assistant 消息，旧历史完整保留，已有原文去重；先后不明时只附带有时间的本轮资料。新话题优先，短应声只在确实接着最近那条实际发送时聚焦；不将应声当执行、转告或充值成功。新建或切换对话不接入已绑定其他对话的记录。无活动对话的发送可在第一轮绑定；无法查询对话归属时仅保留记录、不猜归属。原余额衔接作为共用入口不可用时的降级，升级不重置通知账本。

明确忘记片段时，共用记录也按本人和请求范围清理正文，并留仅含编号的排除记录，防止旧余额通知再次导入。这不声称删除了 QQ 原始消息或其他存储。状态接口不输出消息正文、号码或私有路径；对话及发送账本不进入公开仓库。

表达上区分想法、正在执行和未来交付。没有对应依据时，去掉“我慢慢画”“画完先给你看”“稍后会通知”等常见承诺；不把它改成已完成，也不因模型许诺而创建任务。原文、引文、明确故事、用户自己的创作和表达为想法的计划保留。`future_task` 与 `dafeiyu_tasks` 的提醒确认都要核对实际任务和归属；规则仍只覆盖常见表达，不能代替全部事实核实。

近况中含实际困难时优先按求助处理，避免删掉必要问题；接梗反问保留。随口讲吃饭等生活时减少未经请求的指导。称呼目录按话题加载，本人的有效称呼和事实校验保留。

随机自动语音最多等待 8 秒，未完成保留本轮文字，不重试；明确要求语音或保存的语音偏好保留原提供商预算，常规 45 秒、长预算最高 90 秒。音色、提供商、配置概率、单段合成、白名单与管理员豁免均沿用原设置。

数值诊断增加会话锁等待、首个完整模型响应和上下文文本长度，不记录提示或正文。首个完整响应不是流式首字；准备、模型、工具等阶段有包含关系，不应相加。缩短自动合成等待减小同会话排队影响，没有将合成改为后台乱序发送。

197 项本地隔离回归包括 23 项新增用例：主动发送、隔天应声、切新话题、第二位发言者、未知回执、归属隔离、遗忘、承诺和排队诊断。它们使用原生事件及请求钩子、假 QQ 与假提供商，无生产数据或付费调用；不宣称真实模型在多轮聊天中已经完全自然。

部署前核对生产源码基线并备份相关插件，先在断网的生产镜像验证。热更新后核对共用发送观察器、会话锁诊断、原生发送及群策略守护。回滚只恢复此次代码，不覆盖新通知状态、`outgoing.db`、真实聊天、配置或作品；旧版会忽略新的共用记录。
