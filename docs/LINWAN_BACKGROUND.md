# 临湾的角色来历

用户认可的来历：鲸鲸从城外海边小屋搬到沿海城市临湾，租住南桥区老公寓四楼，暂以自由创作者介绍自己，希望独立生活并逐渐发现喜欢的事。旧桌子、写了一半的本子和小芽随她搬来；房间、城市及初来时的小经历沿用确认的草案。

完整背景保存在 `src/dafeiyu/life/world_profile.json`，标记为 `fictional_world`、版本 2。城市地点是可发展的故事环境，兴趣、朋友和职业以后继续形成；没有固定参观路线、活动次数或回复台词。

接入点：

- `persona/live.md` 的身份介绍保留一句简短城市来历，统一对话压缩人设后仍能知道住处；完整详情由已有 `dafeiyu_self(section="fiction")` 按需读取。普通问候不带入整篇来历。
- 夜间规划读取简短角色背景，模型可以选择发展故事，也可以探索、阅读或创作其他内容。选择 `use_world` 时，已有创作流程会读取完整背景，没有额外模型调用。
- 日常状态直接读取当前背景的位置与版本，避免管理状态仍显示旧居为现住处。

旧作品中的海边小屋保留为过去的故事，不重写作品、聊天片段、长期记忆或成长记录。来历是主人认可的角色设定，不是今天执行过的活动，也不证明与真实联系人的共同经历。模型在角色故事中可以自然表达，不需要每句重复说明虚构；被认真问到 AI 身份时仍如实回答。

部署时只迁移正式人设的身份行和 `JINGJING_OWN_LIFE` 段落，其他线上私有关系、动作规则与工具权限原样保留；数据库会先一致备份。通过断网检查、真实人设的隔离装配验证和只读运行状态确认，不使用付费模型测试或 QQ 试发。
