# QQ 空间由主模型自主表达

2026-11-06，版本 `v3.1.3.post14` 已提交、推送并部署；北京时间 14:30 完成只读核验。部署代码 `7d7107db595d3780e6f88e31c79e6eafcd67fa87`，见 [上线证据](qzone-free-expression-deployment-20261106.json)。

用户要求去掉空间文案检查和额外模型审稿，让主模型自行决定发布内容。

- 正文只做一次主生成，不再调用日记审核模型，不重写第二稿；单次模型请求最多尝试一次。
- 删除 10～160 字、160 字日记和 1000 字发布入口的人工长度限制，不截断最终正文；空输出仍记为生成失败。
- 删除相似度阈值、三字片段重合度、天空海洋等意象限制，以及按词语或引号拒绝整篇的规则。
- 删除随机题库、固定文体、固定篇幅目标、强制当天总结与随机构图。公开资料是可选参考，主题、形式和表达由主模型决定。
- 自动配图只生成一次，已有作品与新生成配图均不再交给另一模型审查。
- 空间公开写作不读取私聊、群聊历史、共享记忆或完整私人身份人设；明确提供的公开资料和授权素材可以使用。

原有账号权限、明确指定正文/图片、素材公开许可撤回、日记日期和发布前时间窗检查保留。每天一次的既有排程、先登记再发布、未知结果不重发，以及配图明确失败后的单次纯文字降级保持不变。没有重置失败日期或补发旧动态。

新增有界错误类别：模型接口错误按异常类别或 HTTP 状态记录，超时为 `provider_timeout`，空输出为 `empty_output`。不将服务商响应正文、密钥或生成内容写入错误原因。历史两次 `ValueError` 的底层原因没有足够记录，不能事后推断为已经确认的审核拒绝。
