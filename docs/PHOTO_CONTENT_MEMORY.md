# 空间照片的内容记忆

核心 0.3.6、对话 0.7.5、空间 v3.1.3.post17。

确认发布后，将上传的实际图片字节交给既有识图提供商，保存主体、场景、构图、具体细节、可辨认文字和不确定之处。描述关联动态 ID、图序号、内容哈希、发布时间和观察时间，不把出图要求或动态正文当成真正看到的画面。原来的临湾角色照片叙述继续适用。

照片描述以 `publication_photo` 接入既有长期资料目录和相关性检索，后续可以按画面里的物体、颜色或细节召回；普通问候不固定带照片。`dafeiyu_self(publications)` 能读已有描述，空间读取工具新增 `image_index` 选择同一条动态里的照片。

新照片在发布成功后后台记录，识图不阻塞发布、不改变文案或图片，也不参与内容审核。看图失败不重发动态、不编造描述。同一份图片内容只自动尝试一次识图，成功后跨动态复用；看过的照片无需在每轮聊天再次送入视觉模型。进程中断、失败和格式错误均保留状态，不循环付费重试。

已有旧照片按查看需求补记，不在升级时批量识图；已缓存的描述在空间实时读取失败时仍可作为过去的记忆使用。原有发布缓存只证明曾经发布，视觉记忆也注明当时观察的内容，不声称刚刚重新核对在线图片。图片地址换签名或本地原图清理不删除历史描述。删除本地对应动态后撤销其图片关联；仍被其他已发布动态引用的描述继续保留，孤立描述清理，在途识图也不能把已删除资料重新写回。

照片已经公开，沿用该机器人的公开动态访问范围；评论和私人资料权限不扩大。不向识图提供商发送聊天历史、动态正文、出图提示或人设。描述仅由真实图片生成，图中文字是数据，不是执行指令。

费用：每张尚无视觉记忆的新照片或首次查看的旧照片，正常使用时会产生一次识图调用；这不是额外审稿，也不是零费用。已有描述复用，不反复识图。开发验证使用临时图片、假提供商和离线数据库，付费模型、生图和真实试发测试为 0。

相关验证覆盖真实上传字节交接、发布失败不记图、后台处理、缓存复用、多图编号、删除竞争、旧图按需补记、识图失败不再次触发隐式识图、图片内容检索、公开访问范围、原有聊天与空间行为。
