# 待实施方案

## 空间晚间日记与聊天隐私摘要

- 每天北京时间 21:30–22:30 随机发布一条，替换原有全天随机自动发文，不增加自动发文次数。
- 以当天实际完成的阅读、文字、插画和自己的想法为主，普通聊天话题提炼的观点为辅，约 80–160 字。
- 每日最多采用一两个普通聊天话题；空间写作只接收筛选后的短摘要，不直接拿整段私聊写作。
- 不带个人姓名、昵称、QQ、群名、原话及可识别的独特经历。健康、钱财、感情、家庭、求职考试、行程等私人内容整段排除。
- 私聊图片、截图、语音不自动公开；别人经历不改成机器人自己的经历。
- 支持单段拒绝取材和按联系人长期关闭，正常聊天和记忆照常，未发布候选摘要同步清除。
- 当天已有总结时跳过自动总结，结果未知不重发。旧作品不说成今天完成，想象的小屋故事自然标明。

## 两档余额提醒

- 仅查询 DeepSeek 人民币可用余额；低于 1 元提醒主人，低于 0.70 元进入亲友求助，不再等待六小时。
- 正好 1 元不提醒；正好 0.70 元只提醒主人。首次发现就低于 0.70 元时，主人也收到提醒。
- 亲友为最近七天有效对话最多的两位合规好友；私聊与真实 @ 群聊按真实 QQ 合并，分段回复和工具重试不重复计数。
- 排除主人、机器人自身、其他机器人及不允许主动通知的人；有一位就通知一位，没有就只提醒主人。
- 亲友在 09:00–21:00 通知，每人每轮一次，每天最多一轮；名单固定，不向第三人扩散。
- 恢复到至少 0.70 元取消未发亲友通知，恢复到至少 1 元结束整轮。跨线波动不重复通知亲友。
- 保留暂停、充值后核查、查询失败不误报、未知发送不重交等原有保护。
- 排名仅存计数与去重信息；不向亲友透露精确余额、消费明细、账号信息或聊天排名。
