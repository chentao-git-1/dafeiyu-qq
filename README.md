# 大肥鱼 QQ 机器人

2026-10-30 已实现语义生成、来源学习、任意事项状态、持续项目与反思、主动选择和语音意图候选，本地及生产镜像通过 286 项隔离回归。完整模型回放仍有失败提示与假设误写，整体质量门槛未通过。15:43 核验的生产是 0.2.0 active / 1 个私聊对象，本轮没有覆盖该运行组合或安装新候选。以 [最新实施与验收记录](docs/COGNITION_IMPLEMENTATION.md) 为准；此前 [第二轮记录](docs/SEMANTIC_DIALOGUE_STAGE2.md) 保留历史状态。

基于 AstrBot 4.29.1 与 NapCat / OneBot 的 QQ 机器人源码快照，角色名为「哦鲸鲸」。包含服务器当前部署的 19 个外部插件、AstrBot 后端、对应版本的前端源码和行为回归测试。

## 当前功能

- DeepSeek 对话、图片理解、按语境接图、同会话有来源的回忆与相处偏好。
- 群聊真实 @ 唤醒、引用原消息回复、其他机器人互刷保护与确认送达保护。
- 自然语音、画图、唱歌、提醒任务、约定回访和有限度的主动分享。
- 独立阅读、原创文字、数字插画与明确属于想象的小屋故事。
- QQ 空间配图发布、公开选材、定时互动、评论回复和持久化去重；每天北京时间 21:30–22:30 随机一篇晚间日记。
- 日记优先使用当天已完成且核验过的数字作品，可使用一两条固定词表生成的安全聊天话题摘要；支持“这段别写进总结”和“以后别公开我的聊天”。原始聊天、身份和私人经历不进入公开写作。
- DeepSeek 人民币余额严格低于 1.00 元提醒主人，严格低于 0.70 元进入两位合规好友求助阶段。对象按最近七天确认送达的有效对话排名，每轮锁定、每天最多一轮；恢复到一元才结束整轮。

## 使用

换电脑继续开发，先读 [接手说明](docs/NEXT_STEPS.md) 和 [最新验收记录](docs/COGNITION_IMPLEMENTATION.md)，既有需求见 [实施方案](docs/PLAN.md)，升级与回滚见 [迁移说明](docs/MIGRATION.md)。源码实现不代表生产已经升级，运行版本和开关须在变更前重新核对。

1. 按 `framework/README_zh.md` 安装并启动 AstrBot 4.29.1，按 NapCat 官方说明配置 OneBot。
2. 创建仓库外的身份映射文件，参考 `identities.example.json`，将示例号码替换为自己的号码。
3. 运行 `python scripts/install_plugins.py --target /path/to/AstrBot/data/plugins --identities /private/path/identities.json`，将插件复制并配置到运行目录。脚本不覆盖已有插件目录。
4. 在 AstrBot 本地管理界面配置 DeepSeek、语音、画图、唱歌和 QQ 空间登录信息，再启用所需插件。各插件依赖见对应 `requirements.txt`。
5. 将同一身份映射应用到 `persona/live.md` 后导入人格，并按实际账号配置聊天白名单。不要将本机生成的身份映射、运行配置或数据提交到仓库。

源码里的 `7000000001` 等号码均为示例，无法直接连接原机器人。服务器正在运行的代码与私人配置没有被本次整理修改。仓库没有聊天记录、记忆数据库、账号密钥、QQ/空间登录态或生成作品。

## 验证

导出前的部署版本已通过 334 项回归、11 个真实 DeepSeek 文本场景与空间专项检查。公开导出替换了私人号码，导出后的静态检查及隔离测试结果见 `docs/export-verification.json`。测试不发送真实 QQ 消息，不发布空间，不调用付费图像或语音生成。

可运行不依赖框架的测试：`python tests/test_persona_tuning.py plugins`。安装框架依赖后，可运行 `python scripts/run_tests.py` 执行隔离的原生事件测试。

新增纯逻辑测试：`python tests/test_evening_features.py plugins`。完整入口同时包含旧的人格回归和新的真实插件入口、余额发送、日记排程、素材撤回与发布传输测试，使用临时目录、假提供商和捕获发送。

历史连续性改造通过 197 项项目回归；当前完整入口已扩展至 **286 项**，本地及生产镜像隔离验证见 [本轮数值证据](docs/cognition-verification.json)。自动语音最多等待 8 秒，明确语音要求保留提供商预算；历史行为边界见 [对话衔接](docs/CONTINUITY.md)。测试不包含整个上游框架测试集，也不能替代真实模型、真人盲评或生产长期验证。

## 许可与来源

第三方代码保留各自目录下的原始许可证与作者信息。来源与版本见 `THIRD_PARTY.md`。自定义插件许可由仓库所有者另行确定。

公开聊天取材采用保守的固定话题词表，不承诺总结所有聊天。新统计从升级后真实确认的回复开始积累，不从旧累计计数或聊天库推算七天历史。
